# To-Do List 

## Description
The To-Do List  is a simple Python project that helps users manage their daily tasks through a command-line interface.

## Features
- Add new tasks
- View all tasks
- Remove tasks by task number
- Handle invalid inputs
- Simple menu-driven interface

## Technologies Used
- Python 3

## How to Run
1. Install Python 3.
2. Run the `To_Do_List.py` file.
3. Select an option from the menu to add, view, or remove tasks.

## Purpose
This project helps beginners understand Python lists, functions, loops, conditional statements, and exception handling.
